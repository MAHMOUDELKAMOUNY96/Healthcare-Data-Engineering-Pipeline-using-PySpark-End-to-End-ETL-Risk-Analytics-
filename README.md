# Healthcare Data Engineering Pipeline using PySpark

## Project Overview
This project demonstrates an end-to-end Healthcare Data Engineering pipeline built using PySpark.

The pipeline processes patient healthcare records, performs data cleaning and transformation, generates analytical KPIs, and builds a star schema model consisting of fact and dimension tables.

---

## Technologies Used
- PySpark
- Python

---

## Key Features
- Data Cleaning & Profiling
- KPI Generation
- Feature Engineering
- Patient Risk Scoring
- Fact & Dimension Modeling
- Window Functions
- ETL Pipeline Design

---

## Business Insights
- Number of visits per patient
- Most common diseases
- Drug usage analysis
- High-risk patient identification

---

## Data Model

### Fact Table
- fact_visits

### Dimension Tables
- dim_patient
- dim_drug
- dim_disease

---

## Risk Scoring Logic
Patients are classified into:
- High Risk
- Medium Risk
- Low Risk

Based on:
- Visit count
- Disease count
- Drug count
